# Анкета ОТиПБ — Vega Development

Веб-анкета для новых работников и визитёров: собирает сведения об обучениях
и допусках, формирует сводную таблицу из 52 колонок и отправляет её письмом
ответственным сотрудникам.

Персональные данные на сервере не хранятся: заполненная анкета уходит письмом,
загруженные сканы удаляются сразу после отправки.

## Из чего состоит

| Каталог | Что внутри |
|---|---|
| `app/` | Анкета и генератор ссылок — React 19 + Vite 8 + Tailwind 4 |
| `backend/` | Приём анкет, сводная таблица, письма — Node.js 20 + Express 5 |

## Быстрый старт

```bash
cd app && npm install && npm run dev        # анкета на localhost
cd backend && npm install && node server.js # бэкенд на порту 3002
```

Бэкенду нужен файл `.env` (в репозиторий не входит):

```
SMTP_USER=ящик, с которого уходят письма
SMTP_PASS=его пароль
ADMIN_PASS=пароль генератора ссылок
```
